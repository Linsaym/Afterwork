# Afterwork

Десктопный трекер продуктивности для Windows 10/11 x64. React + TypeScript работают в WebView2, Rust/Tauri отвечают за таймер, JSON-хранилище, трей и работу с играми.

## Команды

- `npm ci` устанавливает зависимости из lock-файла.
- `npm run check` собирает фронтенд, проверяет Rust через rustfmt и Clippy, запускает тесты.
- `npm run dev:preview` открывает браузерное превью на http://localhost:1422. Сценарии описаны в `DEVELOPMENT.md`.
- `npm run dev:desktop` запускает Afterwork Dev с отдельным каталогом данных. Используй его для проверки Tauri. Блокировку проверяй тестом на временном `.exe`.
- `npm run tauri -- build` собирает NSIS-установщик. Запускай для проверки упаковки и релизных изменений.

## Карта проекта

- `src/main.tsx` — оболочка, таймер, настройки. `activities.tsx`, `statistics.tsx`, `games.tsx` и `achievements.tsx` — соответствующие экраны.
- `src/desktop.ts` — команды и диалоги Tauri, `src/types.ts` — типы IPC. Контракт проверяется общими примерами в `fixtures/`.
- `src-tauri/src/main.rs` — Tauri, атомарное сохранение, блокировки и IPC. `actions.rs` меняет состояние, `model.rs` считает время и статистику, `achievements.rs` начисляет награды.
- `game_catalog.rs` и `game_detector.rs` распознают игры, `game_tracking.rs` ведёт историю, `game_icons/` работает с иконками.

## Правила поведения

- Таймер учитывает сон и перезапуск, пауза останавливает учёт. Статистика делит сессию по настраиваемой границе дня. У достижений отдельная граница в 06:00.
- Архивирование занятия и исключение игры сохраняют прошлые сессии. Уже запущенная игра продолжает работу при включении блокировки.
- При смене формата JSON проверь чтение прежних данных и запись с повторным открытием. Используй синтетические примеры и временные каталоги.
- При изменении IPC сверь Rust, TypeScript и общие примеры. При изменении UI проверь затронутый сценарий в превью или Afterwork Dev. Укажи выполненные и пропущенные проверки в отчёте.
