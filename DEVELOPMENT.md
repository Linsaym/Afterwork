# Разработка Afterwork

Afterwork — приложение для Windows 10/11 x64 на Tauri 2, Rust, React и TypeScript. Загрузки и первый запуск описаны в [README](README.md).

## Сборка из исходников

Нужны Node.js из `.node-version`, Rust из `rust-toolchain.toml` с хостом `x86_64-pc-windows-msvc`, Visual Studio Build Tools с C++ и Windows SDK, а также Microsoft Edge WebView2.

```powershell
npm ci
npm run check
npm run dev:desktop
```

Afterwork Dev открывает окно Tauri и использует `%APPDATA%\app.afterwork.desktop.dev\afterwork.json`. При первом запуске доступны стандартные занятия и пустая история. Сессии сохраняются между запусками. В этом профиле отключены системные уведомления о фокусе, регистрация автозапуска, поиск игр, автоматическое обновление иконок и блокировка файлов. Чтобы завершить процесс, выберите «Выйти из Afterwork» в трее. Для проверки блокировки используйте тест `enrollment_blocks_new_launches_and_exclusion_keeps_history` с временной копией `ping.exe`.

`npm run dev:preview` запускает интерфейс на http://localhost:1422. Параметр `scenario` принимает значения `empty`, `active`, `archive`, `locked`, `error` и `game-stats`. Последний добавляет игровые сессии по обе стороны от границ периодов суток, включая полночь. По умолчанию видны активная сессия, архивное занятие и тестовая игра. Изменения данных хранятся в памяти до перезагрузки страницы. Windows-диалоги и трей проверяются в Afterwork Dev.

Для диагностики распознавания настоящих игр запустите обычный debug-профиль:

```powershell
$env:AFTERWORK_GAME_DIAGNOSTICS = '1'
npm run tauri -- dev
```

Обычный debug-профиль работает с основным каталогом данных и реальными играми. Завершите установленную копию через трей перед запуском. Диагностика выводит локальные пути, источник распознавания и причины пропуска или неполной блокировки в терминал.

Сборка установщика:

```powershell
npm run tauri -- build
```

Готовый бинарный файл находится в `src-tauri\target\release\afterwork.exe`, установщик — в `src-tauri\target\release\bundle\nsis`.

## Выпуск обновлений

Afterwork проверяет [манифест последнего выпуска](https://github.com/Linsaym/Afterwork/releases/latest/download/latest.json) при запуске. Скачанный пакет проверяется по открытому ключу и подписанной версии. Установка начинается только после подтверждения в приложении; прогресс установки показывает NSIS. Afterwork Dev и локальная сборка без открытого ключа не проверяют реальные выпуски. В браузерном превью `?scenario=update` имитирует скачивание, подтверждение и запуск установщика на фоне активной сессии, а `?scenario=update-offline` — ошибку сети.

Перед первым выпуском с обновлениями один раз выпустите ключ Tauri с паролем. Храните приватный ключ и пароль в защищённой резервной копии: установленные версии доверяют этому ключу и не примут подпись от нового.

```powershell
npm run tauri -- signer generate --write-keys "$env:USERPROFILE\.tauri\afterwork.key"
```

В настройках GitHub **Settings → Secrets and variables → Actions** задайте:

- Переменную `TAURI_UPDATER_PUBLIC_KEY` — содержимое файла `afterwork.key.pub`.
- Секрет `TAURI_SIGNING_PRIVATE_KEY` — содержимое файла `afterwork.key`.
- Секрет `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` — пароль ключа.

Для выпуска укажите одинаковую новую версию в `package.json`, `package-lock.json`, `src-tauri/Cargo.toml`, `src-tauri/Cargo.lock` и `src-tauri/tauri.conf.json`. Отправьте тег вида `v0.6.0`. [Workflow выпуска](.github/workflows/release.yml) проверит версии, соберёт подписанный установщик Windows x64 и добавит его, файл `.sig` и `latest.json` в черновик GitHub Release. Проверьте файлы и опубликуйте выпуск как Latest. У уже выпущенной версии 0.5.0 нет обновлятора: первый выпуск с этой функцией нужно установить вручную поверх неё. Установщик использует прежний идентификатор приложения и сохраняет прежний каталог данных.

## Таймер, хранение и блокировка

По умолчанию новый день начинается в 06:00. После 45 минут фокуса игры доступны до 16:00. В 16:00 для доступа нужно 90 минут суммарно за день. Все 90 минут можно набрать заранее. Настройки расписания вступают в силу при сохранении. Календарь и дневные итоги используют текущее время начала дня.

Закрытие окна сворачивает приложение в трей. Нажмите на значок Afterwork, чтобы открыть окно. Правой кнопкой мыши можно открыть меню, поставить сессию на паузу, продолжить её или полностью выйти. После полного выхода блокировка снимается до следующего запуска приложения. Запущенный секундомер учитывает прошедшее время, включая сон компьютера и перезапуск приложения. Пауза останавливает учёт. Сессия на границе дня засчитывается по частям. Напоминание приходит не чаще одного раза за час до выполнения дневной цели.

Afterwork блокирует открытие выбранных файлов средствами Windows, пока работает в фоне. Уже запущенные игры продолжают работу. Лаунчер или обновление могут временно удерживать файл открытым. В таком случае Afterwork показывает состояние файла и повторяет попытку через несколько секунд. Данные находятся в `%APPDATA%\app.afterwork.desktop\afterwork.json`.

## Распознавание игр

Afterwork читает локальные каталоги Steam, Epic Games, GOG, Ubisoft Connect и данные Riot Games для League of Legends и VALORANT. Если достоверный путь к игре найден в каталоге или по структуре установки, блокировка может вступить в силу уже до первого запуска. В остальных случаях Afterwork запоминает исполняемый файл при первом распознавании окна игры. Для игр вне каталогов используются признаки Unity и Unreal Engine. Если признаки отсутствуют, её можно добавить вручную.

Время учитывается с момента обнаружения до завершения процесса, включая время, пока игровое окно свёрнуто. После долгого сна или перезапуска создаётся новый отрезок. Текущая сессия сохраняется примерно каждые 20 секунд и при выходе через трей. «Исключить» отключает дальнейший учёт и блокировку, сохраняя прошлые сессии. В статистике «Неделя» и «Месяц» показывают последние 7 и 30 календарных дней соответственно.

## Иконки игр

Afterwork ищет иконки в исполняемом файле, ярлыках рабочего стола и меню «Пуск» и локальном кэше Steam. Для игр с известной карточкой магазина приложение может загрузить изображение у Steam или Riot. При поиске по названию используется только точное однозначное совпадение в каталоге Steam. Приложение передаёт идентификатор либо название игры, а пути к файлам и история остаются на компьютере. Если источник недоступен, отображается стандартная иконка. При снятии блокировки Afterwork может повторно проверить локальный файл.

Кнопка «Изменить иконку» в строке игры открывает выбор PNG, JPG или ICO до 8 МБ и 4096 × 4096 пикселей. Свою иконку можно заменить или сбросить кнопкой «Вернуть автоматическую». Изображения хранятся в `%APPDATA%\app.afterwork.desktop\game-icons-v1`. Неудачные интернет-запросы кэшируются на шесть часов.

## Достижения

Каталог показывает прогресс и полученные награды. Награды начисляются один раз. Секретные появляются только при получении. Серии и дневной прогресс для наград считаются по местным дням с 06:00. Для нового прогресса дневная цель берётся из настроек, а для старых дней без сохранённых настроек применяется стандартная цель в 90 минут. Три прежние награды также переносятся по правилам предыдущей версии.

Для наград, где важен порядок запусков или отсутствие игрового времени, приложение проверяет, что игровой трекер охватывал нужный промежуток. Старые измеренные игровые сессии учитываются там, где достаточно самого факта игры. «Полуночник» требует сохранённого времени завершения сессии.
